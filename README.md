# IPA Phonetic Symbol Keyboard & Translator

## 概要
IPA（国際音声記号）のクリック式キーボード。子音・母音・超分節素の記号ボタンをクリックしてテキストボックスに発音記号を挿入し、コピーボタンでクリップボードにコピーできる。

## 機能
- 母音・肺気流子音・非肺気流子音・超分節素の全カテゴリカバー
- クリックでテキストエリアのカーソル位置に挿入
- コピーボタン（クリップボードAPI）
- クリアボタン
- 英語音素→IPA早見表（クリックで挿入可）

## 使い方
記号ボタンをクリックすると出力テキストエリアに挿入されます。テキストエリア内でカーソル位置を選択した状態でボタンを押すと、その位置に挿入されます。完成したIPA文字列は「Copy」ボタンでクリップボードにコピーできます。
